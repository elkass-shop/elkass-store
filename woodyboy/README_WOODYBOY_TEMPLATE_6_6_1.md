# WOODYBOY TEMPLATE 6.6.1

Ten folder potwierdza, że fundament ELKASS 6.6.1 jest przygotowany także jako baza pod kolejne sklepy/witryny WOODYBOY.

## Co przenosimy do kolejnych projektów
- CMS z szybkim startem
- Kreator produktu krok po kroku
- Kategorie → podkategorie → produkty
- Media Manager
- Biblioteka terminów
- Karta produktu premium
- Motywy sezonowe jako moduł
- Cloud Foundation pod Supabase
- Tryb local fallback
- Prosta migracja na własną domenę

## Jak używać
1. Skopiuj projekt.
2. Zmień branding, kolory, logo i dane kontaktowe.
3. Zmień drzewo kategorii.
4. Podłącz nowy projekt Supabase.
5. Wgraj własne grafiki.

To jest baza do tworzenia kolejnych stron/sklepów, a nie tylko jednorazowy projekt ELKASS.
