ELKASS Cloud Setup

Ten ekran pomaga przygotować stronę do Supabase. Po konfiguracji panel admin będzie mógł zapisywać produkty, kategorie, zdjęcia i promocje online.

1Utwórz projekt w Supabase Free
2Uruchom SQL z pliku supabase/schema.sql
3Wklej URL i anon key do js/supabase-config.js
4Zmień enabled: true
5Commit + Push na GitHub
← Wróć do panelu admina
