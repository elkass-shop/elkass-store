# ELKASS 6.0 WOW THEME REBUILD

## Cel
Motywy sezonowe mają wyglądać jak pełne kampanie marketingowe, a nie tylko zmiana koloru i ikonka.

## Dodano
- `js/elkass-60-wow-theme-rebuild.css`
- `js/elkass-60-wow-theme-rebuild.js`
- `admin/theme-rebuild-60.html`

- Standard
- Boże Narodzenie
- Mikołajki
- Wielkanoc

- Lato
- Jesień

## Mobile-first
Motywy ograniczają dekoracje na małych ekranach, aby nie zasłaniać treści i nie spowalniać strony.

## Przeglądarki
Kod używa CSS i JS bez zewnętrznych bibliotek. Zaprojektowany pod Chrome, Edge, Firefox, Safari i Samsung Internet.
