# ELKASS 6.3.1 CATEGORY TREE PREMIUM

Dodano pełne drzewo kategorii RTV/AGD, aktywność kategorii i podkategorii, opisy premium oraz panel `admin/category-tree-manager-631.html`.

Strona główna pokazuje 6 głównych kafli. Kafel pokazuje maksymalnie 3 podkategorie i przycisk `Zobacz więcej`. Kliknięcie prowadzi do `category.html?cat=...`, gdzie wyświetlane są podkategorie lub informacja o produktach.

Grafiki można zmieniać w panelu lokalnie; po wdrożeniu chmury zapis będzie wspólny na każdym urządzeniu.
